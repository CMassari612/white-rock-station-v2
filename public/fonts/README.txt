Drop the Selawik web font files here:

  selawik.woff2           (weight 400 - regular)
  selawik-semibold.woff2  (weight 600)
  selawik-bold.woff2      (weight 700)

Where to get them:
  1. Download the official Selawik fonts (TTF) from Microsoft:
     https://github.com/microsoft/Selawik/releases
  2. Convert the TTFs to .woff2 with a free tool like https://transfonter.org
     (upload the TTFs, enable woff2, download, and place the files here).

Once these files exist, the whole site renders in Selawik automatically.
Until then, the site falls back to Segoe UI (Windows) / system fonts.
